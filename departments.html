Computer Science (CS)

Focuses on software engineering, algorithm design, system programming, and computational theory to build robust applications.

  • Software Engineer / Developer
  • Full-Stack Web Developer

Information Systems (IS)

Bridges technology and business by focusing on database administration, data analytics, and enterprise system management.

Career Opportunities:

  • Data Analyst & BI Developer
  • Database Administrator
  • Systems Analyst

Information Technology (IT)

Specializes in computer networks, cloud infrastructure, system security, and hardware-software integration.

Career Opportunities:

  • Cybersecurity Specialist

Artificial Intelligence (AI)

Delves into machine learning, deep neural networks, computer vision, and natural language processing to build smart systems.

Career Opportunities:

  • Machine Learning Engineer
  • AI Research Scientist
  • Computer Vision Specialist
